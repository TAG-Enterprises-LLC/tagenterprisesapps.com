T-G-Apps 5 Card Draw Release Log

A summary of significant application changes.

Release 2.1.0

Normalized T-G-Apps 5 Card Draw to the shared T-G-Apps family look and feel, using T-G-Apps YZ as the baseline.

  • Updated user-visible application and company branding from TAG to T-G-Apps.
  • Replaced the setup and game screens with the shared felt-background, full-width gold button style used across the T-G-Apps family.
  • Converted About, How to Play, Release Log, and History to Privacy-style HTML documents rendered in a web view.
  • Added the shared T-G-Apps Catalog and advertising components.
  • Added full translation of the setup screen, game screen, and information documents into Spanish, French, German, Portuguese, and Japanese.

Release 2.0.1

Build: 3

Release type: Corrective release

Released: July 26, 2026

  • Corrected the shared music package path to match T-G-Apps 21.
  • Matched T-G-Apps 21 by carrying music preferences into the game, configuring and starting playback in the game screen, observing app lifecycle changes, and explicitly stopping playback before returning to Setup.

Release 2.0.0

Build: 2

Release type: Major feature release

Released: July 26, 2026

  • Aligned shared T-G-Apps packages, card and chip presentation, betting controls, and saved Settings with T-G-Apps 21 and T-G-Apps 7 Card Draw.
  • Removed duplicate local card and chip assets.
  • Added Privacy-style HTML How to Play, About, History, and Release Log pages.
  • Added an upper-left Setup-return arrow.
  • Added persistent named-player bank History with Continue, Start Over, and Change Name choices.

Release 1.0.0

Build: 1

Release type: Baseline

Released: July 11, 2026

Established the initial five-card draw game with setup, ante, two fixed-limit betting rounds, draw, robots, showdown, split pots, and in-session banks.
